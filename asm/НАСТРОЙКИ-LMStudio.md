# Настройки LM Studio: памятка

LM Studio — это **ваша личная проверка модели** (порт 1234). Агент работает на
llama.cpp (`build\llm\serve.cmd`, порт 8080), где все эти значения уже прописаны.
Так что файл нужен для двух случаев: прогоны задач в чате LM Studio и быстрый
взгляд «а как мы договорились».

Правило: после загрузки модели настройки сохранить **по модели**
(`My Models` → шестерёнка у карточки → параметры по умолчанию), иначе при
следующем запуске они сбросятся к заводским.

---

## Gemma 4 12B it QAT UD (наша рабочая модель)

Проверка: `Estimated Memory Usage (Beta)` — GPU должно выйти ≈ **9–10 ГБ**,
Total ≈ 8 ГБ. Если GPU показывает больше 11 — снизить контекст до 48K или
отгрузку слоёв до 46.

| настройка | сейчас (после сброса) | поставить |
|---|---|---|
| Context Length | 8192 | **65536** |
| GPU Offload | 25 | **48** (все слои; у 12B их 48) |
| CPU Thread Pool Size | 4 | **6** |
| Max Concurrent Predictions | 4 | **1** (агент ходит по одному запросу) |
| Context Checkpoints | 32 | **8** |
| K Cache Quantization | выкл | **Q8_0** |
| V Cache Quantization | выкл | **Q8_0** |
| Speculative Decoding | Off | **MTP-драфтер** (см. ниже) |
| Flash Attention | вкл | оставить вкл (без него KV Q8_0 не включится) |
| Offload KV cache to GPU | вкл | оставить |
| Unified KV Cache | вкл | оставить |
| Keep Model in Memory | вкл | оставить |
| Try mmap() | вкл | оставить |
| Evaluation / Physical Batch | 2048 / 512 | оставить (штатные) |
| RoPE Frequency Base / Scale | Auto | оставить |
| Seed | Random | оставить |
| llama.cpp Arguments Override | ВЫКЛ | оставить |

**MTP (Speculative Decoding).** Выбрать драфтер `mtp-gemma-4-12B-it.gguf`
(254 МБ; в LM Studio — поиск по `mtp-gemma`). Параметры драфта: максимум токенов
**4**, порог **0,75**, остальное 0/по умолчанию. Если файла драфтера в LM Studio
нет — оставить `Off`: это только скорость, вывод не меняется, и в движке агента
MTP включён отдельно.

**Сэмплинг** (ниже настроек загрузки). Значения — по карточке модели (Unsloth —
Google): у Gemma 4 рекомендованы именно такие, и они же дают совпадение с прогонами
в движке:

| параметр | после сброса | поставить |
|---|---|---|
| Temperature | 0.1 | **1.0** |
| Top K Sampling | 40 | **64** |
| Top P Sampling | 0.95 | оставить **0.95** |
| Min P Sampling | 0.05 | **выкл** (или 0.01) |
| Repeat Penalty | вкл, 1.1 | **выкл** |
| Presence Penalty | выкл | оставить выкл |

Почему так: у думающих моделей низкая температура и штраф повтора дают зацикливание
на рассуждении и портят структурный вывод (штраф наказывает повторяющиеся скобки и
запятые в JSON — а они там законны). Официальные значения для Gemma — 1.0/0.95/64.

**Прочие переключатели в этом же окне:**

| параметр | значение | почему |
|---|---|---|
| Limit Response Length | выкл | пусть решает модель; ставить предел имеет смысл только в замерах, чтобы поймать «убежавшую» генерацию |
| Context Overflow | Truncate Middle | сохраняет начало (системный промпт) и конец (задача). Если увидите, что контекст обрезался, — лечится **увеличением контекста**, а не сменой режима |
| Stop Strings | пусто | не нужны |
| Structured Output | **выкл** | включает принудительный JSON на **весь** ответ: наши задачи требуют прозу + код + JSON в одном сообщении — грамматика их сломает. Для строгого JSON у нас свой разбор и проверка в конвейере; включать её на постоянку нельзя |

**Важно про движок агента:** `app.py` передаёт в модель свою температуру
(`ASM_LLM_TEMPERATURE`, по умолчанию **0.2**), а `build\llm\serve.cmd` сэмплинг не
задаёт вовсе. То есть всё это окно влияет **только на чат LM Studio** (наши ручные
прогоны задач). Путать не нужно: агент работает по своим значениям.

## Qwen3-Coder-Next (пробник, для сравнения)

| настройка | значение |
|---|---|
| Context Length | **32768** |
| GPU Offload | **Max** (оценка VRAM ≤ 10,5 ГБ) |
| Number of layers … force MoE expert weights onto CPU | **40** (это то, что дало 9,6 → 25,4 ток/с; при нехватке памяти — 48) |
| Number of Experts | **10** (обученное значение, не трогать) |
| CPU Thread Pool Size | **6** |
| Max Concurrent Predictions | **1** |
| Context Checkpoints | **8** |
| K / V Cache Quantization | **Q8_0 / Q8_0** |
| Flash Attention | **вкл** |
| Offload KV to GPU / Keep in memory | вкл |
| Speculative Decoding | **Off** |
| Сэмплинг | temp **1.0**, top-p **0.95**, top-k **40**, min-p **0.01**, repeat penalty **выкл** |

Ожидаемая скорость — 22–25 ток/с (при закрытых браузере и Discord обычно выше).

## Если настройки снова сбросятся

1. Открыть эту памятку: `НАСТРОЙКИ-LMStudio.md`.
2. Выставить по таблице своей модели, затем `My Models` → шестерёнка → сохранить
   как параметры по умолчанию.
3. Быстрая проверка после загрузки: контекст, отгрузка слоёв, KV Q8_0,
   Flash Attention, один параллельный запрос. Этого достаточно, чтобы цифры
   скорости и поведения были сопоставимы с прошлыми прогонами.
