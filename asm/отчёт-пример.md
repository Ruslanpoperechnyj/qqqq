#### 1. CVE-2021-26691 в Apache HTTP Server 2.4.7 — по данным NVD

* **Приоритет:** **P0** — закрыть в течение 24–72 часов
* **Объект:** `45.33.32.156:80` (порт 80)
* **Оценка риска:** 143.6
* **Почему так оценено:** CVSS 9.8 — CRITICAL (база 96); сервис опубликован в интернет по HTTP (×1.15); EPSS 68% — эксплойт с высокой вероятностью (×1.30)
* **Суть:** In Apache HTTP Server versions 2.4.0 to 2.4.46 a specially crafted SessionHeader sent by an origin server could cause a heap overflow
* **Признак обнаружения:** CPE из публичного индекса: cpe:/a:apache:http_server:2.4.7
* **Затронуто:** 45.33.32.156:80
* **Первоисточник:** https://nvd.nist.gov/vuln/detail/CVE-2021-26691

**Как закрыть** (Известная уязвимость (CVE) в компоненте):

  * Обновить пакет веб-сервера до актуальной версии ветки 2.4 (или новее), перезапустить службу
  * Отключить лишние модули: mod_status, mod_info, mod_autoindex — если они не нужны
  * Запретить листинг каталогов: Options -Indexes
  * Ограничить доступ к служебным путям (server-status, .git, .env) на уровне конфигурации
  * Обновить компонент до версии с исправлением
  * Если обновление недоступно — временно ограничить доступ к сервису
  * Проверить, не эксплуатировалась ли уязвимость: логи, процессы, задания в cron

  ```bash
  # Debian/Ubuntu
  sudo apt update && sudo apt install --only-upgrade apache2 && sudo systemctl restart apache2
  # RHEL/CentOS/Astra
  sudo dnf update httpd && sudo systemctl restart httpd
  # запрет листинга каталогов: в <Directory> добавить
  Options -Indexes
  # проверить подозрительные задания
  ```
